# Ricochet Protocol

A 3D arena survival game made for the Hack Club Haven game jam theme **Bounce Back**. Your shield is your only way to fight. Aim a returned shot at a drone to destroy it, or send a heavy orb into a group for splash damage.

## Run in Godot

Import `project.godot` into Godot 4.6 or newer and press **F5**. The project uses the Compatibility renderer. All geometry and sound are generated by the project at runtime.

| Input | Action |
| --- | --- |
| WASD or arrow keys | Move |
| Mouse | Aim |
| Left click or Space | Activate your shield briefly |
| H | Toggle aim assist |
| Esc | Pause or resume |
| M | Toggle sound |
| Enter | Start, resume, or play again |
| R | Restart from pause or the results screen |

Red rounds are standard shots. Large gold orbs come from heavy drones. A close, precisely timed shield activation turns a shot gold and increases its damage. A missed return costs time while your shield recharges. Clear all five waves to win.

## Publish to itch.io

Install matching Godot export templates and select **Project → Export → Web**. The preset uses single-threaded export. Export to `index.html` inside a new folder. ZIP the contents with `index.html` at the root and upload it to an itch.io **HTML Game** page. Mark the ZIP as playable in the browser and test the page before submitting.

## Tune the game

`arena.gd` holds the wave positions, starting shield health, return timing, projectile speeds, and visuals. `arena.tscn` is the main scene.
